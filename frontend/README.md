# Snaptle Frontend

이 프론트엔드는 Lovable로 생성한다. Lovable은 자신이 관리하는 저장소를 통째로 소유하는 방식으로 동작해서,
기존 백엔드 코드가 있는 이 모노레포의 `frontend/` 서브폴더에는 직접 동기화되지 않고 **별도의 새 저장소**를
만든다. 억지로 하나의 모노레포로 합치면 이후 Lovable 편집분이 자동 동기화되지 않으므로, Lovable이 만든
저장소를 프론트엔드의 정식 저장소로 그대로 사용한다 (`Snaptle` 조직 아래 별도 repo, 예: `snaptle-frontend`).

이 폴더(`frontend/`)에는 코드가 들어가지 않으며, 연동 방법과 디자인 브리프만 기록해둔다.

## Lovable 연동 순서

1. [lovable.dev](https://lovable.dev)에서 새 프로젝트를 만들고, 아래 "Lovable에 붙여넣을 설명"을 그대로 입력해 1차 초안을 생성한다.
2. Lovable 프로젝트 설정에서 **GitHub 연동(Connect to GitHub)**을 클릭한다. `Snaptle` 조직에 새 저장소가 생성되도록 진행한다.
3. 생성된 저장소 이름을 알려주면, 이어서 백엔드 API 연결(base URL, 인증 토큰 처리)과 Vercel 배포를 진행한다.

## Lovable에 붙여넣을 설명 (초안 생성용)

```
Snaptle이라는 여행 정산 서비스의 웹 프론트엔드를 만들어줘.

컨셉: 친구/가족과 여행할 때 각자 결제한 영수증을 사진으로 올리면 AI가 금액/가맹점/통화를
자동 인식하고, 여행이 끝나면 누가 누구에게 얼마를 보내야 하는지 자동으로 계산해주는 서비스.
지금은 사진 업로드가 핵심이지만, 나중에 오픈뱅킹/카드 자동연동이 추가될 수도 있어서
브랜드 정체성을 "사진 찍기"에만 지나치게 묶지는 않을 거야.

컬러: 메인은 웜톤(코랄/선셋 오렌지 계열, 예: #FF7A59 근처)로 여행의 설렘과 따뜻함을 표현하고,
서브/포인트는 딥 네이비 또는 틸(예: #1B3A4B 근처)로 정산·금액처럼 신뢰가 필요한 요소에 사용해줘.
숫자(금액)는 항상 크고 명확하게, 등록/성공 등 확정 액션은 웜톤, 정산 결과·잔액 같은 신뢰가
중요한 화면은 네이비/틸을 주로 써줘.

아이콘/일러스트 톤: 브랜드 전체를 카메라 아이콘에 과하게 의존하지 말고, 영수증/보딩패스 느낌의
티켓 모티프를 메인 심볼로 써줘 (사진으로 찍든 나중에 자동연동으로 들어오든 결국 하나의 "기록된 거래"라는
의미). 카메라 아이콘은 영수증 촬영 버튼에만 한정해서 쓰고, 비행기 모티프는 로딩 화면이나 빈 상태(empty state)
일러스트 정도로 가볍게만 사용해줘.

톤 & 무드: 여행의 설렘이 느껴지되 정산은 신뢰감 있고 명확하게 보여야 함. 밝고 따뜻한 톤,
카드형 레이아웃. 모바일 브라우저에서 보기 좋은 반응형 웹.

핵심 화면:
1. 로그인/회원가입 — 이메일 로그인 + "카카오로 시작하기" 버튼
2. 내 여행 목록 — 카드 형태로 여행 이름/기간/멤버 아바타, "새 여행 만들기" / "초대코드로 참여하기" 버튼
3. 여행 상세 — 상단에 여행 정보(이름/기간/기본통화/초대코드 공유), 지출 목록(날짜순, 카테고리 필터: 식비/숙소/교통/기타), 우측 하단 플로팅 버튼으로 "지출 추가"
4. 지출 추가 — 영수증 사진 업로드(카메라/갤러리) → AI 인식 결과(가맹점/금액/통화/날짜)를 보여주고 사용자가 수정 가능 → 결제자 선택, 참여자 선택(균등분할 기본, "직접 입력"으로 커스텀 금액 분할 전환 가능) → 저장
5. 개인 간 채무 — 여행과 별도로 "OO에게 내기 대금 5000원 받을 돈" 같은 걸 기록하는 탭
6. 정산 결과 — "여행 종료" 버튼 클릭 시 각자 얼마 냈고 얼마를 내야 하는지, 최종적으로 "A가 B에게 15,000원 보내기" 같은 송금 목록을 카드로 명확하게 표시

아직 백엔드 연동은 없어도 되니, 목업 데이터로 화면 흐름과 디자인을 먼저 완성해줘.
React + TypeScript + Tailwind로 만들어줘.
```

## 백엔드 연동 시 참고사항

- 백엔드 저장소: [`Snaptle/snaptle`](https://github.com/Snaptle/snaptle) (`backend/` 폴더), API 문서는 [`backend/README.md`](https://github.com/Snaptle/snaptle/blob/dev/backend/README.md)
- 인증: `Authorization: Bearer {accessToken}` 헤더 방식 (JWT, stateless)
- CORS: 백엔드가 모든 오리진을 허용하도록 이미 설정되어 있어(`SecurityConfig`), 프론트 배포 URL이 정해지면 별도 백엔드 수정 없이 바로 연동 가능
- 통화: `KRW`, `USD`, `JPY`, `CNY`, `EUR`
- 지출 카테고리: `FOOD`, `LODGING`, `TRANSPORT`, `ETC`
